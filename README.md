# AugmentWorks Cursor Plugin

Starter repository for the planned AugmentWorks integration with Cursor.

The plugin will help developers configure regression tests for an HTTP agent, review failures, and compare results after a fix. It will use the existing AugmentWorks CLI for test execution and reporting.

- [AugmentWorks CLI](https://github.com/augmentworks-org/augmentworks-cli)
- [Current coding assistant setup guide](https://augmentworks.ai/docs/agent-setup)
